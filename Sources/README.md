# ViKey sources

- `OpenKey/engine`: the typing engine (C++), shared by the app and the tests.
- `OpenKey/macOS`: the macOS app (Xcode project `OpenKey.xcodeproj`, product `ViKey.app`).

ViKey only ships for macOS. The Windows and Linux code of OpenKey is in the [OpenKey repository](https://github.com/tuyenvm/OpenKey).
